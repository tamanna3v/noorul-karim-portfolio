# Engr. Md. Noorul Karim — Portfolio

Professional portfolio website of Engr. Md. Noorul Karim, B.Sc. Engg., EMBA.

## About this project

A single-page, static website (HTML, CSS and a small amount of vanilla JavaScript). It has no build step and no dependencies apart from Google Fonts.

Sections:
- About
- Professional Experience
- Institution of Engineers, Bangladesh (IEB) service, as a timeline
- Other Affiliations

All content is taken from source material supplied by the portfolio owner's representative. Nothing has been added beyond what the source states.

## Deployment

- **Hosting:** GitHub Pages, deployed from the `main` branch, root folder.
- **Custom domain:** configured through the `CNAME` file and the repository's Pages settings, with DNS managed in GoDaddy.

## Local preview

Open `index.html` in any browser. No server is needed.

## Updating content

Edit `index.html` and commit to `main`. GitHub Pages redeploys automatically within a few minutes.
